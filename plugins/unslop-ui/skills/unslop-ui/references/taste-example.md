# Taste

What this team wants gone from its interface copy. Save it as `.unslop-ui/taste.md` at the project root and `/unslop-ui` reads it on every run. Edit the bullets, delete the ones you do not care about. Write them in any language.

## Bans

Each bullet is one more tell. The first three have a fixed id and a search pattern (T1, T2 and T3). The rest are read by the agent.

- Exclamation marks
- Uppercase text, not only eyebrows
- Middle dots between items
- Emoji, including in docs
- Gradients
- The word "seamless", or its equivalent in your language

## Keep

Nothing here is cut or rewritten, whatever a rule says. The report lists it under "Kept on purpose".

- The Beta badge in the header
- Legal text in the footer

## Off

Rule ids to skip entirely (`U11`, `T1`, `unslop 13`), each followed by its reason. A skipped rule is neither counted nor applied. Only the ids at the start of the bullet count, so a reason can mention other rules.

- U11, our product names include emoji
- unslop 13, the brand writes with dashes
